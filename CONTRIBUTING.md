# Contributing to Awesome Trading Resources

Thank you for your interest in contributing! This document provides guidelines for adding resources to this list.

## How to Contribute

1. **Fork** this repository
2. **Add your resource** to the appropriate section in `README.md`
3. **Submit a Pull Request**

## Guidelines

### What belongs here

- Open-source trading tools and libraries
- Free trading APIs and data sources
- Educational resources (courses, tutorials, blogs)
- Trading-related datasets (free or academic)
- Community resources (forums, subreddits, Discord servers)

### What does NOT belong here

- Commercial/paid-only products without free tiers
- Affiliate links or referral codes
- Spam or self-promotion without substantive value
- Outdated or unmaintained projects (no updates in 3+ years, unless still widely used)

### Format

```markdown
- [Resource Name](URL) - Brief one-line description.
```

### Rules

1. **One resource per PR** — easier to review and merge
2. **Alphabetical order** within each section
3. **Concise descriptions** — 1-2 sentences maximum
4. **Direct links only** — no affiliate, referral, or tracking parameters
5. **Existing sections first** — propose new sections only if no current section fits
6. **Verify links** — make sure the URL works and points to the correct resource

## Code of Conduct

Be respectful, constructive, and inclusive. We're all here to help traders find great resources.
